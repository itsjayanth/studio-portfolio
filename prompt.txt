# Project: Studio Portfolio

Build a modern, premium, responsive UI-only website for a photography and videography studio based in Bengaluru, Karnataka.

## Tech Stack
- React
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion (subtle animations)
- shadcn/ui components
- Lucide Icons

No backend.
No authentication.
No database.
Use placeholder images from Unsplash or Pexels.
Focus entirely on UI/UX.
